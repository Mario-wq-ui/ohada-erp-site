Une solution de gestion intégrée

OHADA ERP INTEGRAL rassemble dans un même environnement les activités de gestion et de comptabilité de votre entreprise.

Une installation sur votre ordinateur

L'application est installée localement sur le poste de l'entreprise. Sa base de données est également hébergée dans l'environnement local prévu pour l'installation. Le site Internet sert à présenter le logiciel et à distribuer son installateur : il ne constitue pas l'environnement de travail de l'application.

Les domaines de votre gestion

Un environnement de travail orienté vers les besoins de gestion et de suivi comptable de l'entreprise.

Comptabilité

Gestion des opérations comptables dans le cadre du référentiel SYSCOHADA.

Gestion financière

Un environnement intégré pour suivre les activités financières de l'entreprise.

Environnement local

Une application Windows installée sur l'ordinateur de l'entreprise, avec une base de données locale.
